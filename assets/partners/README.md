# Logos partenaires

Fichiers destinés aux ressources publiques de Match Europe. Ils sont affichés dans le bandeau de la page principale d’administration Flask.

- `eures-ela.jpg` : copie exacte du fichier fourni `LOGOS/EURES_ELA/EURES_ELA_logos_combined.jpg`.
- `adem.png` : rendu PNG à 300 dpi du fichier fourni `LOGOS/ADEM/Logo_Adem_H_Denomination.pdf`, page et proportions conservées.
- `forem.png` : logo officiel téléchargé le 15 octobre 2026 depuis https://www.leforem.be/content/dam/leforem/fr/images/logos/Logo-Forem-noir.png (page source : https://www.leforem.be/charte-graphique). La signature personnelle fournie dans `LOGOS/FOREM/` est exclue.

- `france-travail.svg` : copie exacte du bloc marque officiel « République française + France Travail », horizontal, couleurs positives, RVB, extrait le 15 octobre 2026 de https://logo.francetravail.org/fichier/8/download (fichier source : `LogoFranceTravail/Bloc Marque RVB/Couleurs/Bloc_Marque_RF_France_Travail_RVB_Horizontal_Coul_Positif.svg`). Remplace la copie du favicon précédemment préparée. Le fichier est affiché sans modification dans le bandeau d’administration.

Aucun logo distinct de l’Union européenne, document de charte graphique ou fichier de configuration n’est ajouté.

## Utilisation ultérieure du logo France Travail

Source : https://logo.francetravail.org/ ; guide téléchargé depuis https://logo.francetravail.org/fichier/9/download, archive contenant `France Travail - Guide utilisation logo - 120326.pdf`. La charte reste hors du dépôt.

- Version principale : horizontale, sur fond blanc, sans déformation, adaptation ou altération (page imprimée 3).
- Le bloc République française accompagne France Travail dans la version principale ; garder l’association et les proportions du fichier fourni (page imprimée 10).
- Zone de protection : aucun texte, image ou autre élément à moins d’un diamètre du cercle bleu clair le plus haut du symbole (page imprimée 7).
- Taille minimale indiquée : 12 mm de largeur ; le guide ne donne pas ici de valeur en pixels (page imprimée 7).
- Ne pas changer couleurs, composition, proportions ou typographie (page imprimée 8).
- Une version verticale est admise pour certains supports, notamment une série de logos partenaires (page imprimée 4) ; le fichier conservé ici est la version principale horizontale.

L’intégration dans l’administration conserve les fichiers et leurs proportions, sur fond blanc avec espacement entre les marques. La conformité complète à la charte reste à valider.
